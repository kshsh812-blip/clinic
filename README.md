## 이 저장소의 파일은 직접 고치지 않아요

고칠 일은 전부 Claude 프로젝트에 말로 부탁하세요. Claude가 고친 파일을 만들어 주거나, GitHub가 연결되어 있으면 직접 올려 줘요.

- 캐릭터, 앱 아이콘 바꾸기: "이 그림으로 캐릭터랑 앱 아이콘 바꿔 줘"
- 학부모 문자 말투 바꾸기: "학부모 문자 말투를 내 문자처럼 바꿔 줘" + 실제로 보낸 문자 5~10개

## 연습 모드

서버 주소를 넣기 전에는 연습 모드로 열려요. 예시 학생과 기록이 들어 있고, 새로고침하면 처음으로 돌아가요.
비밀번호: 선생님 `123456`, 예시 학생(김지호) `1234`, 학부모 `12345`

## 구조 (Claude가 참고하는 내용)

| 자리 | 무엇 | 어디에 |
|---|---|---|
| 화면 | `index.html`(학생, 선생님, 학부모 화면 전부), `sw.js`, `icons/`, 매니페스트 2개, `report/` | 이 저장소 → GitHub Pages |
| 서버 | Apps Script: `Code.gs`(로그인, 저장, 시트 입출력, 선생님 비밀번호) + `omr`(무한선지 채점, 등수, 리포트) | 내 구글 계정 |
| 데이터 | 구글 시트 탭 `students` `sets` `items` `subs` `checks` `parents` `fbs` | Apps Script가 붙어 있는 스프레드시트 |

학생 이름, 기록, 비밀번호는 전부 구글 시트에만 있어서 이 저장소를 공개해도 보이지 않아요. 단, **`Code.gs`는 이 저장소에 절대 올리지 마세요.** 선생님 비밀번호가 들어 있어요.
